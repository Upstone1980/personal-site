# chrisupstone.me — Personal Site

Static HTML/CSS personal website. No build step required.

## Structure

```
/
├── index.html           # Home — Founder · Operator · Investor
├── about.html           # Full career history
├── contact.html         # Contact info
├── blog/
│   ├── index.html       # Blog listing
│   └── posts/
│       └── from-experiment-to-expectation.html
├── css/
│   └── style.css        # All styles
└── README.md
```

## Deploy

Serve from any static host (Netlify, Cloudflare Pages, GitHub Pages, S3, VPS, etc.).

No build command needed — just point the host to the root directory.
